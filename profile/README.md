# Estado X

**[Español](#español) · [English](#english)**

## Español

**Estado X** es una plataforma colombiana de innovación pública. Conecta gobierno, tecnología y sector privado para convertir ideas en soluciones institucionales reales.

### Repos abiertos para Colombia

Cada semana tomamos una herramienta de código abierto y la adaptamos a la realidad colombiana: datos oficiales del país, normas colombianas y español. Así cualquiera puede usarla.

Cada repo trae:
- una **demo** que se abre en el navegador;
- el **código** para instalarla por tu cuenta;
- una guía en **español** y en **inglés**.

**Crédito primero.** Cada adaptación dice de qué proyecto viene, quién lo hizo y con qué licencia. Solo adaptamos proyectos cuya licencia lo permite, y conservamos la licencia original.

## English

**Estado X** is a Colombian public innovation platform. It connects government, technology and the private sector to turn ideas into working institutional solutions.

### Open repos for Colombia

Every week we take an open-source tool and adapt it to Colombia: the country's official data, Colombian regulations and Spanish. That way anyone can use it.

Each repo includes:
- a **demo** you can open in the browser;
- the **code** to install it yourself;
- a guide in **Spanish** and **English**.

**Credit first.** Every adaptation states the original project, its author and its license. We only adapt projects whose license allows it, and we keep the original license.
